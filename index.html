Get Together!

A side project I built entirely with AI: a mobile-first app that helps groups of 5 to 50 friends land on a date and time that works for everyone.

Hosts propose a few time slots and invite friends by text or email. Attendees tap the times they can make, and the host sees the best windows ranked by how many people can come, then sends a confirmation and collects RSVPs.

  • AI pair programming
  • Firebase Firestore
  • GitHub Pages
Try Get Together!
  1. Started with a PRDI wrote it the way I would at work: target users, host and attendee flows, success metrics and MVP scope.
  2. Vibe coded the front endI handed the PRD to AI and iterated in plain language, screen by screen, testing on phones and different screen sizes.
  3. Built the backend on FirebaseFirestore stores events, time slots and responses, so hosts and attendees see the same live data.
  4. Shipped a working prototypeLive on GitHub Pages, with native text and email invites that keep the MVP lean.
